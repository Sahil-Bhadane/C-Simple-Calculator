# C Simple Calculator

A simple menu-driven calculator written in C.

This project was created as part of my C programming practice to understand `switch` statements, conditional statements, user input, and basic problem-solving.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero validation
- Invalid choice handling
- Decimal result for division

## Concepts Practiced

- Variables and data types
- `printf()` and `scanf()`
- `switch` statement
- `case`
- `break`
- `default`
- `if-else`
- Type casting
- `return`
- Basic input validation
